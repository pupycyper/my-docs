# 关于本项目

## 项目目标

实现从 Markdown 文档到公开网站的自动化发布。

## 技术组成

| 工具 | 作用 |
| --- | --- |
| Markdown | 编写文档内容 |
| MkDocs Material | 将文档构建成静态网站 |
| GitHub Actions | 自动执行安装、构建和部署 |
| GitHub Pages | 托管并提供网站访问地址 |

## 我的理解

这四个工具分工明确：Markdown 负责写内容，MkDocs 把内容变成网页，Actions 负责自动执行整个流程，Pages 负责把网页放到互联网上让别人访问。
