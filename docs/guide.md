# 使用指南

1. 修改 docs 目录中的 Markdown 文件。
2. 在本地预览并检查页面及链接。
3. 提交修改并推送到 main 分支。
4. 在 Actions 页面查看构建与部署状态。
5. 打开网站检查内容是否更新。

## 常用命令

| 命令 | 作用 |
| --- | --- |
| `python -m mkdocs serve` | 本地预览 |
| `python -m mkdocs build --strict` | 构建网站并严格检查警告 |

## 我的使用心得

推送前先在本地预览一遍，可以提前发现链接写错或格式不对的问题，避免把有问题的内容直接发布出去。

接口说明见 [API 参考](api.md)。
