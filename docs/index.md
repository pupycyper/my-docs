## 我的实践体会

这次实践让我明白，写文档和发布网站可以连成一条自动化流程：我只需要修改 Markdown 并推送，剩下的构建和部署都由 GitHub Actions 完成。相比手动上传文件，这种方式更省事，也更不容易出错。
